# Dataset Information

This repository does **not** include the datasets used for training and evaluation.

Datasets have been excluded because:

* Several datasets have their own licenses and redistribution policies.
* The combined dataset size exceeds typical GitHub repository limits.
* Users should download datasets directly from their original sources to ensure compliance with licensing terms and obtain the latest versions.

## Datasets Used

### Phase 1

* RAVDESS

### Phase 2

* RAVDESS
* CREMA-D
* TESS
* SAVEE
* EMO-DB
* ESD
* Hindi Emotional Speech Corpus
* JL Emotional Speech Corpus

## Download Sources

Please obtain the datasets from their official sources:

Download links:

- RAVDESS: https://www.kaggle.com/datasets/uwrfkaggler/ravdess-emotional-speech-audio
- CREMA-D: https://www.kaggle.com/datasets/ejlok1/cremad
- TESS: https://www.kaggle.com/datasets/ejlok1/toronto-emotional-speech-set-tess
- SAVEE: https://www.kaggle.com/datasets/ejlok1/surrey-audiovisual-expressed-emotion-savee
- EMO-DB: https://www.kaggle.com/datasets/piyushagni5/berlin-database-of-emotional-speech-emodb
- ESD: https://www.kaggle.com/datasets/nguyenthanhlim/emotional-speech-dataset-esd
- Hindi Emotional Speech Corpus: https://www.kaggle.com/datasets/vishlb/speech-emotion-recognition-hindi
- JL Corpus: https://www.kaggle.com/datasets/tli725/jl-corpus

Refer to the official dataset pages, publications, or repositories for download instructions, licensing information, and citation requirements.
